♟️ Chess Board Using HTML & CSS

A simple Chess Board created using HTML and CSS.
This project is made for practicing HTML structure, CSS styling, and grid layout.

📌 Project Preview

This project creates a classic 8×8 chess board using HTML and CSS.

Each square is styled with alternating light and dark colors to create the chessboard pattern.

🛠️ Technologies Used

HTML5 – Used to create the structure of the chess board.
CSS3 – Used for styling, colors, sizing, and layout.

✨ Features

8×8 chess board
64 individual squares
Alternating light and dark squares
Simple and clean design
Built completely with HTML & CSS
Beginner-friendly project
